# جریان | آرشیو شعر فارسی

**نسخه:** `0.1.0b7`  
**زبان‌ها:** [English](README.md) · فارسی

جریان یک وب‌اپ سبک برای کشف، جست‌وجو، خواندن و نگه‌داری شعر فارسی است. پوستهٔ استاتیک مستقل است و با سرور اختیاری Node/SQLite می‌تواند حساب و بازخورد را روی سرور ذخیره کند.

## امکانات

- جست‌وجو در بیت‌های واقعی با نرمال‌سازی حروف فارسی، بارگذاری تأخیری و هایلایت نتیجه‌ها.
- مرور شاعران، مجموعه‌ها و بخش‌های شعر با مسیرهای hash-based.
- خواندن شعر با کپی، اشتراک‌گذاری، ذخیره، لایک بیت و یادداشت محلی.
- حالت تمرکز برای خواندن بیت‌به‌بیت با دکمه‌های قبلی/بعدی و صفحه‌کلید.
- Fab Morph شیشه‌ای برای اشتراک‌گذاری، کپی، حالت تمرکز و اندازهٔ نوشته، همراه با سه سطح اندازهٔ کلی برنامه.
- فاصله‌گذاری اصلاح‌شدهٔ مسیرها، دکمه‌های بزرگ‌تر خانه، Fab شیشه‌ای و نوار ابزار حالت تمرکز.
- کنترل فشردهٔ خروج در حالت تمرکز، شعر فعال بزرگ‌تر و تولبار چهارگزینه‌ای صفحهٔ شعر.
- کارت شاعر دکمهٔ فال شاعر دارد؛ عنوان مجموعه فاصلهٔ بهتری دارد و بیت‌های بلند در اندازه‌های بزرگ روی هم نمی‌افتند.
- زبان انگلیسی با چینش چپ‌به‌راست و سه انتخاب فونت جداست؛ فونت‌های فارسی فقط در حالت فارسی نمایش داده می‌شوند.
- فونت برنامه و فونت شعر جدا شده‌اند؛ فونت شعر راوی، ایران نستعلیق، شکسته نستعلیق و میرعماد را دارد. سه فونت نستعلیق‌محور در `assets/fonts` داخل بسته قرار دارند.
- dock موبایل خارج از پوستهٔ زوم‌شده قرار گرفته تا ورود به آرشیو و جست‌وجو آن را به بالای صفحه نکشد یا صفحه را قفل نکند.
- فهرست تم‌ها شامل «دارک مود»، «لایت مود»، «تیره»، «روشن»، «کاغذی» و «سیستم» است؛ تم سیستم فقط بین پالت پرکنتراست دارک مود و لایت مود انتخاب می‌کند.
- همهٔ دکمه‌های فال از آیکن shine و افکت درخشش کنترل‌شده استفاده می‌کنند.
- باکس جست‌وجو و ورودی‌های حساب و بازخورد دکمهٔ پاک‌کردن دارند.
- حساب مجاز شایان با شمارهٔ مشخص‌شده پنل مدیریت محلی و خروجی داده دریافت می‌کند.
- تم سیستم به‌صورت پیش‌فرض انتخاب می‌شود و کارت‌های آمار حساب جمع‌وجورتر شده‌اند.
- حساب محلی نام نمایشی و شمارهٔ موبایل را به‌عنوان شناسه روی همان دستگاه نگه می‌دارد.
- تم روشن، کاغذی، تیره و هماهنگ با سیستم؛ سطح‌های تعاملی نیز با تم تغییر می‌کنند.
- پروفایل محلی، علاقه‌مندی‌ها و تاریخچهٔ خواندن با `IndexedDB` و پشتیبان `localStorage`.
- سرور اختیاری جدول‌های کاربران، رضایت، snapshot دستگاه و بازخورد را با API نسخه‌دار در SQLite ذخیره می‌کند.
- ارسال نظر فرم داخلی دارد و اگر سرور فعال نباشد، پیام را در صف محلی نگه می‌دارد.
- رابط واکنش‌گرا، dock ثابت و کوتاه‌تر موبایل با تب لغزان خنثی و اطلاعات نصب PWA.
- بارگذاری تنبل متن شعر، فایل‌های فشرده و قطعه‌بندی مجموعه‌های بزرگ.

## ساختار پروژه

```text
index.html                 پوستهٔ برنامه
app.js                     مسیریابی، رندر، وضعیت و تعاملات

fab-morph.tsx              نمونهٔ مستقل Fab Morph برای React/Tailwind
manifest.webmanifest       اطلاعات PWA
service-worker.js          کش پوسته و داده‌ها
data/catalog.json          فهرست شاعران و مجموعه‌ها
data/poem-index.json       نمایهٔ سبک شعرها
data/search.bin            نمایهٔ فشردهٔ جست‌وجوی متن کامل
data/poems/*.bin           مجموعه‌های فشردهٔ شعر
data/poems/chunks/*.bin    قطعه‌های مجموعه‌های بزرگ
assets/                    فونت‌ها و آیکن برنامه
package.json              دستور اجرای سرور اختیاری Node

README.md                 مستندات انگلیسی پیش‌فرض
README.fa.md              همین مستندات به فارسی
```

## اجرای محلی

برنامه باید از طریق HTTP یا HTTPS اجرا شود. بازکردن مستقیم `index.html` با `file://` باعث اختلال در دریافت داده‌ها و ثبت Service Worker می‌شود.

```bash
python3 -m http.server 8080
```

سپس آدرس <http://localhost:8080> را در مرورگر باز کنید. برای ذخیرهٔ حساب و نظر روی سرور، به‌جای آن `npm start` را اجرا کنید؛ همان برنامه با API SQLite روی پورت `8787` اجرا می‌شود.

## انتشار

جریان را می‌توان به‌عنوان سایت استاتیک روی GitHub Pages، Netlify، Vercel یا هر میزبان HTTPS منتشر کرد.

1. محتوای همین پوشه را بارگذاری کنید.
2. ریشهٔ سایت را روی پوشهٔ دارای `index.html` قرار دهید.
3. مسیر پوشه‌های `data`، `assets` و فایل `service-worker.js` را تغییر ندهید.
4. فایل‌های `.bin` را بدون هدر `Content-Encoding: gzip` سرو کنید؛ فشرده‌گشایی در مرورگر انجام می‌شود.

## نکات معماری

جریان با JavaScript خام، یک رندرکنندهٔ کوچک، event delegation و hash routing ساخته شده است. در شروع فقط catalog و poem-index خوانده می‌شوند. متن کامل مجموعه هنگام ورود به آن دریافت می‌شود و نمایهٔ جست‌وجو نیز فقط هنگام شروع جست‌وجوی متنی بارگذاری می‌شود. مجموعه‌های بزرگ به قطعه‌های ۲۵۶تایی تقسیم شده‌اند. حرکت‌ها تا حد امکان با transform، opacity و filter اجرا می‌شوند و تنظیمات reduced motion رعایت می‌شود.

اگر سرور اختیاری فعال نباشد، پروفایل و صف نظر روی همان دستگاه ذخیره می‌شوند. با فعال‌بودن سرور، اطلاعات حساب و دستگاه پس از رضایت کاربر و نظرها در SQLite از مسیرهای `/api/v1/users/upsert` و `/api/v1/feedback` ذخیره می‌شوند.

## بررسی نسخه

این نسخه با موارد زیر بررسی شده است:

- بررسی syntax فایل‌های `app.js` و `service-worker.js`.
- بررسی سلامت فایل ZIP.
- تست مسیرهای شعر در دسکتاپ و موبایل.
- تست باز و بسته‌شدن Fab، رنگ‌های وابسته به تم و بستن با کلیک بیرون.
- تست ذخیرهٔ پایدار، تأیید سبز کپی و حرکت بیت‌به‌بیت در حالت تمرکز.
- بررسی اندازهٔ header/footer، موقعیت اسکرول مسیرها و کنترل‌های واکنش‌گرا.
