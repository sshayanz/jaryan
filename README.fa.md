# جریان | آرشیو شعر فارسی

**نسخه:** `0.6.5`  
**زبان‌ها:** فارسی · [English](README.md)

جریان آرشیوی سبک و دوزبانه برای کشف، جست‌وجو، خواندن و نگه‌داری شعر فارسی است. برنامه به‌صورت سایت ایستا هم اجرا می‌شود؛ سرور اختیاری Node.js همگام‌سازی اعضا با رضایت، دریافت نظر، شمارش تجمیعی بازدید و اشتراک و پنل مدیریتی جداگانه را اضافه می‌کند.

## امکانات

- مرور شاعران، مجموعه‌ها و شعرها یا جست‌وجوی بیت‌ها با یکسان‌سازی متن فارسی و برجسته‌کردن نتیجه‌ها.
- خواندن شعر در حالت تمرکز، تغییر اندازه و فونت، کپی و اشتراک‌گذاری، علاقه‌مندی، یادداشت و تاریخچهٔ محلی.
- انتخاب فارسی یا انگلیسی، چینش راست‌چین یا چپ‌چین، تم‌های گوناگون و فونت جداگانه برای برنامه و شعر.
- ذخیرهٔ شعرهای انتخابی برای خواندن آفلاین روی همان دستگاه.
- صفحهٔ جریان با یک بیت تصادفی، پربازدیدترین شاعران و شعرها، فال حافظ و مولانا، بیت‌ها و شعرهای پراشتراک و تازه‌ترین شاعران آرشیو.
- نصب به‌شکل PWA در مرورگرهای پشتیبانی‌شده.
- نگه‌داری حساب و سابقهٔ مطالعه در همین مرورگر. پیش از فرستادن اطلاعات حساب و دستگاه به سرور اختیاری، رضایت گرفته می‌شود؛ گذرواژهٔ حساب به سرور ارسال نمی‌شود.
- بررسی اطلاعات اعضای رضایت‌داده، دستگاه‌ها، بازخورد و شمارش تجمیعی بازدید شعرها در پنل امن مدیر سرور.

## اجرا بدون همگام‌سازی سرور

پوشه را با HTTP اجرا کنید؛ بازکردن مستقیم `index.html` با `file://` بارگذاری داده‌ها و Service Worker را مختل می‌کند.

```bash
python3 -m http.server 8080
```

سپس <http://localhost:8080> را باز کنید. در این روش حساب، علاقه‌مندی‌ها، یادداشت‌ها و سابقهٔ مطالعه در مرورگر می‌مانند. همگام‌سازی حساب و دستگاه و ثبت بازخورد در سرور به اجرای Node نیاز دارد.

## اجرای سرور اختیاری

به Node.js نسخهٔ `22.5` یا جدیدتر نیاز است. نصب بستهٔ جداگانه لازم نیست؛ SQLite در خود Node موجود است.

```bash
JARYAN_ADMIN_PASSWORD="یک‌گذرواژهٔ یکتا با دست‌کم ۱۶ نویسه" node server/server.js
```

سرور برنامه و API را به‌طور پیش‌فرض روی درگاه `8787` ارائه می‌کند. برای ورود به پنل مدیریت سرور، نام کاربری `admin` و گذرواژهٔ تنظیم‌شده را وارد کنید. اگر گذرواژه تنظیم نشده باشد یا کمتر از ۱۶ نویسه داشته باشد، ورود مدیر غیرفعال است. نشست مدیر حداکثر هشت ساعت اعتبار دارد و در حافظه نگه‌داری می‌شود؛ با راه‌اندازی دوبارهٔ سرور، مدیر باید دوباره وارد شود.

### تنظیمات سرور

- `PORT` و `HOST`: درگاه و نشانی شبکه؛ مقدار پیش‌فرض `8787` و `0.0.0.0` است.
- `JARYAN_ADMIN_PASSWORD`: گذرواژهٔ یکتای ورود مدیر سرور با دست‌کم ۱۶ نویسه.
- `JARYAN_DB_PATH`: مسیر فایل SQLite که باید بیرون از پوشهٔ عمومی برنامه باشد. مسیر پیش‌فرض `../.jaryan-private/jaryan.sqlite` نسبت به پوشهٔ برنامه است.
- `JARYAN_ALLOWED_ORIGINS`: فهرست جداشده با ویرگول از نشانی‌های دیگری که اجازهٔ دسترسی به API دارند. درخواست هم‌مبدأ نیازی به این تنظیم ندارد.
- `JARYAN_TRUST_PROXY=true`: فقط پشت پراکسی مطمئنی فعال شود که سرآیندهای IP، پروتکل و کشور ارسالی را بازنویسی می‌کند؛ در غیر این صورت این سرآیندها نادیده گرفته می‌شوند.
- `JARYAN_COOKIE_SECURE=false`: فقط برای آزمون محلی روی HTTP؛ در انتشار HTTPS مقدار پیش‌فرض امن را نگه دارید.

فایل SQLite و پشتیبان‌های آن را خصوصی نگه دارید. برای اعضایی که رضایت داده‌اند، فیلدهای پروفایل، زمان رضایت، اطلاعات دستگاه، IP و مرورگر ثبت می‌شود. کشور فقط وقتی از پراکسی مطمئن دریافت شود ذخیره می‌شود. نظر مهمان فقط شامل دسته‌بندی، متن و صفحه است؛ نظر عضو می‌تواند به عضو، دستگاه و اطلاعات درخواست پیوند بخورد. بازدید و اشتراک شعر و بیت فقط به‌شکل شمارش تجمیعی و بدون شناسهٔ فردی ثبت می‌شود؛ بازدید به سابقهٔ مطالعهٔ هر فرد تبدیل نمی‌شود. شمارش اشتراک از این به‌روزرسانی آغاز می‌شود و اشتراک‌های قبلی ثبت نشده‌اند. حساب محلی و گذرواژهٔ آن بارگذاری نمی‌شود.

## انتشار

میزبانی ایستا فقط قابلیت‌های محلی برنامه را فراهم می‌کند. برای قابلیت‌های سرور، Node را پشت HTTPS اجرا کنید یا API را جداگانه میزبانی و پیش از بارگذاری `app.js` مقدار `window.JARYAN_API_BASE` را تنظیم کنید. اگر سایت و API هم‌مبدأ نیستند، همان نشانی دقیق سایت را در `JARYAN_ALLOWED_ORIGINS` قرار دهید. برای ورود مدیر، سایت و API باید هم‌مبدأ یا دست‌کم هم‌سایت باشند؛ کوکی نشست امن به درخواست بین دو سایت فرستاده نمی‌شود. مسیر پوشه‌های `data` و `assets` و فایل `service-worker.js` را تغییر ندهید؛ فایل‌های `.bin` را بدون سرآیند `Content-Encoding: gzip` ارائه کنید.

## ساختار پروژه

```text
index.html                 پوستهٔ برنامه
app.js                     مسیرها، رندر، وضعیت و تعامل‌ها
styles.css                 طراحی واکنش‌گرا، تم‌ها و حرکت‌ها
data/                      فهرست شاعران، نمایه‌ها و شعرهای فشرده
assets/                    آیکن و فونت‌ها
service-worker.js          کش پوسته و داده‌های آفلاین
search-worker.js           جست‌وجوی متن کامل در صورت نیاز
package.json               فرمان‌های اجرا، بررسی و آزمون
server/server.js           میزبان ایستا و API اختیاری SQLite
server/schema.sql          ساختار پایگاه داده
server/server.test.js      آزمون یکپارچهٔ سرور
server/README.md           تنظیمات سرور و API
README.md                  مستندات انگلیسی
```

## بررسی

```bash
npm run check
npm test
```

یا فرمان‌ها را مستقیماً با Node اجرا کنید:

```bash
node --check app.js
node --check server/server.js
node --check service-worker.js
node --check search-worker.js
node --test server/server.test.js
```
