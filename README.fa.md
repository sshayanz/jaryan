# جریان | آرشیو شعر فارسی

**نسخه:** `0.7.0`  
**زبان‌ها:** فارسی · [English](README.md)

> نمونهٔ بازبینی تغییرات حساب در نسخهٔ پیشنهادی 0.7.0؛ این نسخه نهایی نیست.

جریان آرشیوی سبک و دوزبانه برای کشف، جست‌وجو، خواندن و نگه‌داری شعر فارسی است. مرور شعر به‌شکل سایت ایستا هم کار می‌کند؛ حساب‌ها، علاقه‌مندی میان دستگاه‌ها، سابقهٔ مطالعه، فعالیت صفحهٔ جریان و مدیریت به سرور Node.js و پایگاه‌دادهٔ پایدار SQLite نیاز دارند.

## امکانات

- مرور شاعران، مجموعه‌ها و شعرها یا جست‌وجوی بیت‌ها با یکسان‌سازی متن فارسی و برجسته‌کردن نتیجه‌ها.
- خواندن شعر در حالت تمرکز، تغییر اندازه و فونت، کپی و اشتراک‌گذاری، علاقه‌مندی، یادداشت و تاریخچهٔ محلی.
- انتخاب فارسی یا انگلیسی، چینش راست‌چین یا چپ‌چین، تم‌های گوناگون و فونت جداگانه برای برنامه و شعر.
- ذخیرهٔ شعرهای انتخابی برای خواندن آفلاین روی همان دستگاه.
- صفحهٔ جریان با یک بیت تصادفی، شعرهای پربازدید و پرطرفدار، مسیر مطالعهٔ کاربر واردشده، فال حافظ و مولانا، بیت‌ها و شعرهای پراشتراک و تازه‌ترین شاعران آرشیو.
- نصب به‌شکل PWA در مرورگرهای پشتیبانی‌شده.
- ثبت‌نام و ورود از راه سرور انجام می‌شود. اطلاعات پروفایل، گذرواژهٔ هش‌شده با scrypt، علاقه‌مندی‌ها، سابقهٔ مطالعه و فعالیت اشتراک در SQLite ذخیره می‌شوند؛ گزینهٔ یادآوری فقط نام کاربری را نگه می‌دارد.
- مشاهدهٔ اعضا، دستگاه‌ها، بازخورد و شمارش تجمیعی بازدید، پسند و اشتراک در پنل امن مدیر سرور.

## اجرا بدون همگام‌سازی سرور

پوشه را با HTTP اجرا کنید؛ بازکردن مستقیم `index.html` با `file://` بارگذاری داده‌ها و Service Worker را مختل می‌کند.

```bash
python3 -m http.server 8080
```

سپس <http://localhost:8080> را باز کنید. در حالت ایستا می‌توان شعرها را مرور کرد و ترجیح‌های مهمان را محلی نگه داشت؛ ثبت‌نام، ورود حساب، ثبت فعالیت روی سرور و ارسال بازخورد به اجرای سرور Node نیاز دارند.

## اجرای سرور اختیاری

به Node.js نسخهٔ `22.5` یا جدیدتر نیاز است. نصب بستهٔ جداگانه لازم نیست؛ SQLite در خود Node موجود است.

```bash
JARYAN_ADMIN_PASSWORD="یک‌گذرواژهٔ قوی برای مدیر سرور" JARYAN_SHAYAN_PASSWORD="یک‌گذرواژهٔ قوی برای حساب شایان" node server/server.js
```

سرور برنامه و API را به‌طور پیش‌فرض روی درگاه `8787` ارائه می‌کند. در نخستین اجرا، حساب مدیر `admin` و حساب کاربری `shayan` ساخته می‌شوند. پیش از انتشار، `JARYAN_ADMIN_PASSWORD` و `JARYAN_SHAYAN_PASSWORD` را تنظیم کنید؛ گذرواژه‌ها به‌صورت هش scrypt ذخیره می‌شوند. ورود مدیر با نام کاربری `admin` است؛ نشست‌ها در SQLite نگه‌داری می‌شوند و پس از هشت ساعت پایان می‌یابند.

### تنظیمات سرور

- `PORT` و `HOST`: درگاه و نشانی شبکه؛ مقدار پیش‌فرض `8787` و `0.0.0.0` است.
- `JARYAN_ADMIN_PASSWORD`: پیش از انتشار، گذرواژهٔ یکتای مدیر را تعیین کنید؛ در صورت تنظیم، هش مدیر در هر راه‌اندازی تازه می‌شود.
- `JARYAN_SHAYAN_PASSWORD`: گذرواژهٔ حساب اولیهٔ `shayan` که هنگام ساخت نخستین حساب استفاده می‌شود.
- `JARYAN_DB_PATH`: مسیر فایل SQLite که باید بیرون از پوشهٔ عمومی برنامه باشد. مسیر پیش‌فرض `../.jaryan-private/jaryan.sqlite` نسبت به پوشهٔ برنامه است. در همهٔ به‌روزرسانی‌ها همین فایل را روی فضای ذخیرهٔ خصوصی و پایدار نگه دارید.
- `JARYAN_ALLOWED_ORIGINS`: فهرست جداشده با ویرگول از نشانی‌های دیگری که اجازهٔ دسترسی به API دارند. درخواست هم‌مبدأ نیازی به این تنظیم ندارد.
- `JARYAN_TRUST_PROXY=true`: فقط پشت پراکسی مطمئنی فعال شود که سرآیندهای IP، پروتکل و کشور ارسالی را بازنویسی می‌کند؛ در غیر این صورت این سرآیندها نادیده گرفته می‌شوند.
- `JARYAN_COOKIE_SECURE=false`: فقط برای آزمون محلی روی HTTP؛ در انتشار HTTPS مقدار پیش‌فرض امن را نگه دارید.

فایل SQLite و پشتیبان‌های آن را خصوصی نگه دارید. هنگام ثبت‌نام، کاربر با ذخیرهٔ فیلدهای پروفایل، علاقه‌مندی‌ها، سابقهٔ خواندن شعر، رویدادها و اشتراک‌ها، و نیز مشخصات دستگاه، IP و مرورگر موافقت می‌کند. کشور فقط وقتی از پراکسی مطمئن دریافت شود ذخیره می‌شود. گذرواژه فقط به‌صورت هش scrypt ثبت می‌شود. صفحهٔ جریان از بازدیدها، اشتراک‌ها و علاقه‌مندی‌های تجمیعی استفاده می‌کند و مسیر شخصی شعرخوانی کاربر واردشده را نیز نشان می‌دهد. نظر مهمان فقط شامل دسته‌بندی، متن و صفحه است؛ بازخورد کاربر واردشده می‌تواند به حساب و اطلاعات درخواست پیوند بخورد.

## انتشار

میزبانی ایستا فقط قابلیت‌های محلی برنامه را فراهم می‌کند. برای قابلیت‌های سرور، Node را پشت HTTPS اجرا کنید یا API را جداگانه میزبانی و پیش از بارگذاری `app.js` مقدار `window.JARYAN_API_BASE` را تنظیم کنید. اگر سایت و API هم‌مبدأ نیستند، همان نشانی دقیق سایت را در `JARYAN_ALLOWED_ORIGINS` قرار دهید. برای ورود مدیر، سایت و API باید هم‌مبدأ یا دست‌کم هم‌سایت باشند؛ کوکی نشست امن به درخواست بین دو سایت فرستاده نمی‌شود. مسیر پوشه‌های `data` و `assets` و فایل `service-worker.js` را تغییر ندهید؛ فایل‌های `.bin` را بدون سرآیند `Content-Encoding: gzip` ارائه کنید.

## ساختار پروژه

```text
index.html                 پوستهٔ برنامه
app.js                     مسیرها، رندر، وضعیت و تعامل‌ها
styles.css                 طراحی واکنش‌گرا، تم‌ها و حرکت‌ها
data/                      فهرست شاعران، نمایه‌ها و شعرهای فشرده
assets/                    آیکن و فونت‌ها
service-worker.js          کش پوسته و داده‌های آفلاین
search-worker.js           جست‌وجوی متن کامل در صورت نیاز
package.json               فرمان‌های اجرا، بررسی و آزمون
server/server.js           میزبان ایستا و API اختیاری SQLite
server/schema.sql          ساختار پایگاه داده
server/server.test.js      آزمون یکپارچهٔ سرور
server/README.md           تنظیمات سرور و API
README.md                  مستندات انگلیسی
```

## بررسی

```bash
npm run check
npm test
```

یا فرمان‌ها را مستقیماً با Node اجرا کنید:

```bash
node --check app.js
node --check server/server.js
node --check service-worker.js
node --check search-worker.js
node --test server/server.test.js
```
